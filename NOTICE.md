# Project origin

Traffic Vision Lab is a maintained portfolio edition of a shared graduation
project, originally published as **The Eye of God v1.1**.

- Original repository: <https://github.com/muhammetaliyoldar/the_eye_of_god-v1.1>
- Source revision: `e7cd766010075afbc47c117af0edf08a9657d6db` (`master`)
- Original copyright: **Copyright (c) 2025 The Eye of God**
- The original MIT permission and copyright notice are preserved in [LICENSE](LICENSE).

This edition retains and revises the original homography, speed estimation,
signal color, OCR, event detection and SQLite utility design. The main runner
has been rebuilt around explicit configuration, a deterministic synthetic demo
and tests. The old UI scripts, random fallback models, road images, local paths,
contact information and Git metadata are not included.

The project originated as collaborative work. This edition does not claim that
all original code or research was authored by one person. Specific individual
contributions have not been reconstructed from the source history.

Third-party dependencies and any model weights retain their respective licenses;
they are not distributed in this repository.
